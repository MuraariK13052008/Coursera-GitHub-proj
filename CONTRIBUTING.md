## Types of Contributions

### Bug Reports
If you find a bug, please open an issue describing the problem and steps to reproduce it.

### Bug Fixes
If you fix a bug, please open a pull request with a clear description of the fix.

### Documentation Improvements
Help us improve our documentation by fixing typos, clarifying explanations, or adding examples.

### Enhancements & Ideas
Have an idea for a new feature? Open an issue to discuss it before implementing.

## Code of Conduct
Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.
